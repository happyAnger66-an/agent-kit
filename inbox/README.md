# inbox

任务结束时产出的经验候选先落在这里，等整理和人工审核后再晋升。

- 一条经验一个文件：`YYYY-MM-DD-<短名>.yaml`，格式见 `TEMPLATE.yaml`。
- 只收有证据、能复用的经验；没有实测依据的推断标 `confidence: inferred`。
- 领域知识（性能数字、硬件、模型接入、踩坑细节）进 Wiki。这里只收「agent 该怎么做事」的经验：规则、技能、流程的改进。

## 晋升梯度

```text
单次观察 → 对应技能的 FIELD_NOTES.md
       → 出现 ≥3 次 / 跨仓库 → 技能正文的一节
       → 必须遵守的约束 → standards/
       → 可以机器判定 → lint / hook / CI 检查
```

合入后删除 inbox 中的原文件，在 PR 描述里写明落到了哪里。
