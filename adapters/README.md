# adapters

`agentkit sync` 当前只生成 Cursor 规则和一份索引：

| 规范 | 生成结果 |
|---|---|
| 任意 apply | `.cursor/rules/agent-kit/<id>.mdc` |
| 全部命中的规范 | `AGENTS.md` 里 `agent-kit:begin/end` 之间的索引 |
| — | 若 `CLAUDE.md` 不存在，写成 `@AGENTS.md` |

`alwaysApply` 只在 `apply: always` 时为 true。文件头标明 `generated by agent-kit <version> — do not edit`。

`sync --check` 比较这些文件，多出来的 `agent-kit/*.mdc` 也算不一致。
